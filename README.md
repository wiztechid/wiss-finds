# WISS Finds

**Cerita sebelum memilih.**

WISS Finds adalah situs editorial discovery untuk membantu pembaca memahami kebutuhan, membandingkan pilihan, dan menemukan produk yang cocok tanpa pengalaman membaca yang terasa seperti etalase jualan.

## Prinsip
- Soft-selling, reader-first.
- Bedakan Hands-on, Researched, dan Compared.
- Data produk harus diverifikasi sebelum publikasi.
- Affiliate relationship ditandai dengan jelas.
- Artikel tetap berguna meski tautan affiliate dihapus.

## Struktur awal
- `index.html` — homepage editorial.
- `active/walking-pad-untuk-bb-90-kg/index.html` — master article prototype.
- `data/products.json` — database produk terpusat.
- `robots.txt` dan `sitemap.xml` — fondasi crawling/indexing.

Prototype awal. Domain/canonical akan diperbarui saat URL GitHub Pages atau custom domain difinalkan.
